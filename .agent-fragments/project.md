# golded-ftn-hudson

This Python package reads classic Hudson .BBS bases through golded-ftn models.
Use MSGIDX.BBS as authority over 187-byte headers; decode 256-byte Pascal text
blocks before charset detection. The sibling PHP fixtures use the wrong block
format and must not become format tests. GoldBase is a separate format.

Validate active record bounds and metadata before yielding any messages. Keep
physical offsets correct across text-block length bytes. Preserve filesystem
errors; chain parser errors with actual files and offsets. Decode strictly through
core helpers. Reading requires a stable base without concurrent writes.

Use independent synthetic fixtures. Keep private archives out of tests. Run the
README checks and scripts/verify_distribution.py; packed dependencies must use
the public core constraint rather than local checkout paths.

Keep writer, discovery, filtering, database and core changes outside this reader.
Edit this fragment or agent-compose.toml, then preview, build and check. Private
persona sources stay outside distributions. Commits and publication need an
explicit request.

Strict reading stays the default. Archive mode requires an issue callback and
reports every recovery, skipped record and unsafe traversal stop. Keep source
paths, identities and byte offsets in issues; keep message contents out. Callback
failures propagate. Protect both modes with independent synthetic fixtures.
